## 🛠️ Key Skills & Commands Mastered

### 1. Identity & System Context
- **Commands:** `whoami`, `id`, `man`
- **Skills:** Inspecting active execution context, resolving user IDs (`UID`), primary/supplementary group IDs (`GID`), and verifying privilege boundaries before running scripts or administrative tasks.

### 2. File System Navigation & Operations
- **Commands:** `pwd`, `cd`, `ls`, `touch`, `mkdir`, `cp`, `mv`, `rm`, `rmdir`
- **Skills:** Navigating absolute/relative paths, creating directory structures, safely copying/moving/renaming assets, and handling destructive file removal operations.

### 3. File Content Inspection & Comparison
- **Commands:** `cat`, `head`, `tail`, `diff`
- **Skills:** Inspecting full or partial logs/files with line numbering (`cat -n`), analyzing top/bottom stream boundaries (`head`/`tail`), and auditing file differences line-by-line (`diff`) including recursive directory comparison (`diff -r`).

### 4. Permissions & Ownership Management
- **Commands:** `chmod`, `chown`, `sudo`
- **Skills:** Configuring Linux DAC (Discretionary Access Control) using both **symbolic notation** (`u+x`, `g+w`) and **numeric octal notation** (`755`, `644`). Changing file ownership recursively and assigning execution privileges for automated scripts.

### 5. User Account Administration
- **Commands & Configs:** `useradd`, `usermod`, `userdel`, `passwd`, `/etc/passwd`
- **Skills:** Managing the complete lifecycle of local user accounts (creation, locking/unlocking, home directory assignment, shell configuration, and user deletion with/without home directory cleanups).
